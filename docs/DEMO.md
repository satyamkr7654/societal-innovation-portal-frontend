# Demo script (about 8 minutes)

Start with `DEMO_DATA=true`. All accounts use the password `Password123`:

| Role | Email |
|---|---|
| Citizen | citizen@demo.example |
| Admin | admin@demo.example |
| University | university@demo.example |
| Industry | industry@demo.example |

Tip: use a separate browser profile for each role, so you do not sign in and out on stage.

1. **Visitor (30 s).** Open Public Problems. Point out that no names or exact places are shown.
2. **Citizen (90 s).** Report a problem with a photo and a pin. Report near an existing one to show the
   duplicate warning.
3. **Admin (90 s).** The bell shows the new report. Open it, verify it, assign it to Palash Institute Innovation Lab.
   Show the charts and the overdue list.
4. **University (90 s).** Accept the project and submit a proposal with a budget.
5. **Admin (30 s).** Approve the proposal.
6. **Industry (45 s).** Find the proposal and offer part of the budget.
7. **University (60 s).** Accept the offer, complete the four milestones, request completion.
8. **Admin (30 s).** Confirm. The status becomes Solved.
9. **Citizen (30 s).** Show the notifications and timeline, then rate the solution.

**Rules worth showing live:** offer more money than the budget (refused); open an admin page as a citizen
(redirected).

**If something fails:** have the screenshots in `docs/screenshots` open in another tab.
Rehearse once on the same laptop and network; the map needs internet.
